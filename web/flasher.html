Use firmware built for the exact board. This tool does not enable radio transmission; MissionLink RF stays disabled until radio wiring, configuration, security, and Canadian compliance are verified. Never flash files from an untrusted source.

i
Using an iPhone or iPad?

This page opens on iOS 16.7+, but iOS Safari does not support the USB serial API required to write firmware. A native iOS flasher will need a firmware-side BLE OTA update feature before it can safely install builds.
